# khmer24-realestate

A real-estate marketplace frontend inspired by [khmer24.com](https://www.khmer24.com/en).

Built with HTML, Tailwind CSS 4, and vanilla JavaScript — no framework required.

> Implementation lands in the first PR (`feat/initial-frontend`).

## Quick start

```bash
npm install
npm start        # builds CSS and serves on http://localhost:8080
```

## Stack

- HTML5
- [Tailwind CSS 4](https://tailwindcss.com/)
- Vanilla JavaScript
